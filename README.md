# Візуальна навігація AUV за еталонною картою дна (TRN)

Симуляція корекції дрейфу IMU: синтетичний кадр камери шукається на еталонній
карті методом ORB + BFMatcher (тест Лоу) + гомографія з RANSAC.

## Структура
- `data_generator.py` — вирізання випадкового кадру, поворот ±45°, гаусів шум
- `navigator.py` — клас `TerrainNavigator` (ORB, зіставлення, гомографія, поза)
- `main.py` — запуск пайплайна та візуалізація
- `zwoujkzwoujkzw.jpeg` — еталонна карта дна (має лежати поруч зі скриптами)

## Розгортання

1. Перейдіть у папку проєкту:
   ```bash
   cd "/Users/andrii/Documents/Temp/комп зір"
   ```
2. Створіть віртуальне середовище:
   ```bash
   python -m venv venv
   ```
3. Активуйте його (Mac/Linux):
   ```bash
   source venv/bin/activate
   ```
4. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```
5. Запустіть:
   ```bash
   python main.py
   ```

У консолі з'являться розраховані X, Y, кут (та істинні значення для порівняння),
а також два графіки: збіги точок і рамка дрона на карті.

## Примітки
- Кут — це поворот кадру відносно карти (у системі координат зображення, Y вниз).
- Якщо збігів замало, змініть `ratio`, `n_features` у `TerrainNavigator` або
  `noise_sigma` у `generate_frame`.
